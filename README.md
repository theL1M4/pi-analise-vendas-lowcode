# Painel Analítico de Desempenho de Vendas para o Varejo

Projeto Integrador desenvolvido para o Centro Universitário Senac (2º período).

## Objetivo
Estruturar e desenvolver uma aplicação web analítica utilizando o ecossistema low code (Streamlit e Python) para visualização rápida e apoio à tomada de decisão estratégica no setor varejista.
